# Portfolio template

A dark navy Angular portfolio UI with separate components for navigation, hero, about, projects, skills, contact, and footer.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Customize

- Replace the minimal labels and reserved content in `src/app/components/*/*.html`.
- Edit colors, spacing, type, radii, and shadows in `src/styles.scss`.
- Replace the hero visual and About image placeholders with your own assets.
- Update project cards and skill slots in their component templates and TypeScript files.
- Connect the contact form before using it to receive messages. It currently prevents submission and serves as a design preview.
- Add real project and social URLs before enabling those links.

The UI supports responsive layouts, keyboard focus, reduced motion preferences, smooth section navigation, and a mobile menu.

Technology icons come from [Devicon](https://github.com/devicons/devicon). The SVGs and their MIT license are stored in `public/icons`.
